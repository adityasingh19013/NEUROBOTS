# ImpactTrace

Upload messy Excel/CSV files, clean and check the data, merge duplicate people, and publish a report where every
number links back to the original file and row.

Demo login: `demo@impacttrace.org` / `impact123`. The sample project **Digital Literacy 2026 – Q1** is loaded on start.
Data you add is lost when the Space restarts.
